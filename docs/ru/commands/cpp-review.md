# C++ Code Review

Эта команда вызывает агента **cpp-reviewer** для комплексного C++-специфичного обзора кода.

## Что делает эта команда

1. **Выявить изменения C++**: найти изменённые `.cpp`, `.hpp`, `.cc`, `.h` файлы через `git diff`
2. **Запустить статический анализ**: выполнить `clang-tidy` и `cppcheck`
3. **Сканирование безопасности памяти**: проверить на сырые new/delete, переполнения буфера, use-after-free
4. **Обзор конкурентности**: проанализировать потокобезопасность, использование mutex, data races
5. **Проверка современного C++**: убедиться, что код следует конвенциям и лучшим практикам C++17/20
6. **Сгенерировать отчёт**: категоризировать проблемы по серьёзности

## Когда использовать

Используйте `/cpp-review`, когда:
- После написания или изменения кода C++
- Перед коммитом изменений C++
- Обзор pull request с кодом C++
- Онбординг в новую кодовую базу C++
- Проверка на проблемы безопасности памяти

## Категории обзора

### CRITICAL (обязательно исправить)
- Сырые `new`/`delete` без RAII
- Переполнения буфера и use-after-free
- Data races без синхронизации
- Command injection через `system()`
- Чтение неинициализированных переменных
- Обращение к null-указателям

### HIGH (следует исправить)
- Нарушения Rule of Five
- Отсутствующий `std::lock_guard` / `std::scoped_lock`
- Отсоединённые потоки без правильного управления жизненным циклом
- C-style приведения вместо `static_cast`/`dynamic_cast`
- Отсутствующая корректность `const`

### MEDIUM (рассмотреть)
- Ненужные копии (передача по значению вместо `const&`)
- Отсутствующий `reserve()` на контейнерах известного размера
- `using namespace std;` в заголовках
- Отсутствующий `[[nodiscard]]` на важных возвращаемых значениях
- Избыточно сложное template metaprogramming

## Запускаемые автоматические проверки

```bash
# Статический анализ
clang-tidy --checks='*,-llvmlibc-*' src/*.cpp -- -std=c++17

# Дополнительный анализ
cppcheck --enable=all --suppress=missingIncludeSystem src/

# Сборка с предупреждениями
cmake --build build -- -Wall -Wextra -Wpedantic
```

## Пример использования

```text
User: /cpp-review

Agent:
# C++ Code Review Report

## Проверенные файлы
- src/handler/user.cpp (изменён)
- src/service/auth.cpp (изменён)

## Результаты статического анализа
✓ clang-tidy: 2 предупреждения
✓ cppcheck: нет проблем

## Найденные проблемы

[CRITICAL] Утечка памяти
Файл: src/service/auth.cpp:45
Проблема: сырой `new` без соответствующего `delete`
```cpp
auto* session = new Session(userId);  // Утечка памяти!
cache[userId] = session;
```
Исправление: использовать `std::unique_ptr`
```cpp
auto session = std::make_unique<Session>(userId);
cache[userId] = std::move(session);
```

[HIGH] Отсутствующая const-ссылка
Файл: src/handler/user.cpp:28
Проблема: крупный объект передан по значению
```cpp
void processUser(User user) {  // Ненужная копия
```
Исправление: передать по const-ссылке
```cpp
void processUser(const User& user) {
```

## Резюме
- CRITICAL: 1
- HIGH: 1
- MEDIUM: 0

Рекомендация: FAIL: блокировать merge, пока проблема CRITICAL не исправлена
```

## Критерии одобрения

| Статус | Условие |
|--------|-----------|
| PASS: Approve | нет CRITICAL или HIGH проблем |
| WARNING: Warning | только MEDIUM-проблемы (merge с осторожностью) |
| FAIL: Block | найдены CRITICAL или HIGH проблемы |
