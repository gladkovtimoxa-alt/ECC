# Статус русской локализации (docs/ru/)

Этот файл честно фиксирует реальное покрытие перевода на русский на момент последнего обновления, по аналогии с тем, как `docs/zh-CN/` стала полной локализацией только за несколько релизов. Цель — не выдавать частичный перевод за полный.

## Готово

- **README.md** — полный перевод (уже было в main до этой ветки).
- **agents/** → `docs/ru/agents/` — **71/71 файлов, 100%**. Все субагенты переведены полностью, включая frontmatter (description), Prompt Defense Baseline, весь контент и примеры кода с переведёнными комментариями.
- **commands/** → `docs/ru/commands/` — **частично, см. ниже**.

## В процессе / известные пробелы

- **commands/** (98 файлов всего) — переведена только часть (см. список файлов в `docs/ru/commands/` на момент чтения этого файла). Остальные команды пока на английском в `commands/`.
- **rules/** (122 файла, включая `rules/common/` и языковые поддиректории) — перевод **не начат**. Это высокоприоритетный кандидат для следующего прохода — короткие, философские файлы с наивысшей ценностью для нового русскоязычного читателя.
- **skills/** (314+ файлов `SKILL.md` плюс `references/`, суммарно ~6.4 МБ) — перевод **не начат**. Это самая объёмная часть репозитория (сопоставимо по объёму со всем остальным репозиторием вместе взятым) и требует отдельного многосессионного усилия, аналогичного тому, что потребовалось для `docs/zh-CN/skills/`.
- **Топ-уровневые гайды** (`the-shortform-guide.md`, `the-longform-guide.md`, `the-security-guide.md`, `TROUBLESHOOTING.md`, `COMMANDS-QUICK-REF.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `AGENTS.md`, `SOUL.md` и т.д.) — перевод **не начат**.
- **contexts/, examples/, hooks/, plugins/** (аналоги секций docs/zh-CN) — перевод **не начат**.

## Как продолжить

Эта ветка (`l10n-ru`) резюмируема: каждая группа файлов коммитилась отдельно, так что можно продолжать с любой точки. Рекомендуемый порядок по ценности для читателя:

1. Завершить `commands/` (оставшиеся файлы).
2. `rules/README.md` + `rules/common/*.md` (8 файлов, самый большой выигрыш за наименьший объём).
3. Топ-уровневые гайды.
4. `skills/` — начинать с наиболее используемых/часто ищемых навыков, а не по алфавиту; возможно, разумно портировать подмножество, соответствующее `docs/tr/` или `docs/es/` (частичное покрытие — уже признанный в проекте паттерн), а не гнаться за паритетом с `docs/zh-CN/` (416 файлов) с первого раза.

Этот файл следует обновлять при каждом значимом продвижении, чтобы `docs/ru/README.md` и реальное покрытие не расходились.
